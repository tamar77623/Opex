# Opex - Smart Web Dashboard & Search Launcher

Opex is a customizable, Google-inspired start page and search launcher built with pure HTML, CSS, and JavaScript. It features local user authentication, smart search shortcuts, dark/light mode, and quick access to top global platforms.

---

## ✨ Features

* **Smart Search System:** Type custom shortcuts directly in the search bar (e.g., `yt [query]` or `gpt`) to navigate or search specific platforms instantly.
* **Local User Authentication:** Sign up and log in securely using browser `localStorage` to manage personalized sessions.
* **Dark & Light Mode:** Seamless toggle between light and dark themes to match your preference.
* **Quick Links Dashboard:** Clean, minimalist interface providing instant access to the world's most-used platforms (YouTube, ChatGPT, GitHub, etc.).
* **Pure Vanilla Stack:** Built completely without external frameworks or heavy libraries.

---

## 🛠️ Technologies Used

* **HTML5:** Semantic structure and layout.
* **CSS3:** Modern styling, flexbox/grid, and theme variables.
* **JavaScript (ES6+):** DOM manipulation, event handling, conditional search routing, and `localStorage` management.
